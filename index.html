Upload a chest X-ray. See what the model finds.

A model trained on more than 21,000 chest X-rays sorts each image into COVID-19, Normal, Lung opacity or Viral pneumonia, and shows how confident it is in each.

Research demo only. Not a medical diagnosis.

Result

Add an image, then choose Analyse image.

Works on frontal chest X-rays like those it was trained on. Other kinds of image give meaningless results. Your image goes only to the model server set in this page.

How it works

  1. UploadChoose a scan from your device.
  2. PreprocessOpenCV reads the X-ray, converts it to grayscale and resizes it to 224 × 224.
  3. AnalyseA MobileNetV2 model scores all four classes.
  4. Read the resultYou get the most likely class and a score for each.

About the model

A MobileNetV2 network pre-trained on ImageNet, with a new four-class output layer trained on the COVID-19 Radiography Database. After removing exact duplicates there were 21,111 X-rays, split 70 / 15 / 15 into training, validation and test sets. The results below are from the 3,167 test images.

What this means: the model missed about 1 in 7 COVID-19 images in the test set. The test images come from the same public dataset as the training images, so X-rays from other hospitals or machines will probably score worse. The model has not been clinically validated.

Run it yourself

The notebook was written for Google Colab. Open it in Colab to download the data, train the model and see every chart.

To use the trained model on your own computer, start the server, then open this page:

git clone https://github.com/omk1112/Covid19_OpenCV.git
cd Covid19_OpenCV
pip install fastapi uvicorn python-multipart opencv-python-headless numpy "tensorflow>=2.16"
uvicorn api:app --port 8000
